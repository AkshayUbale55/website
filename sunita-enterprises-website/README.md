# Sunita Enterprises — Responsive Multi-page Website

A ready-to-deliver static website created from the supplied **Company Profile 2026–27 Latest.pdf**.

## Pages
- Home
- About
- Services
- Projects (search + year filter)
- Team
- Equipment
- Gallery (responsive lightbox)
- Quality & Safety
- Contact (client-side validation)

## Features
- Fully responsive layout for desktop, tablet and mobile
- Sticky navigation with mobile menu
- Scroll reveal animations
- Homepage statistics
- Project search and year filtering
- Image gallery with lightbox
- Contact form validation
- No build step and no framework required
- Original company profile PDF included in `docs/`

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Production note
The contact form is intentionally front-end only. Connect `assets/script.js` form handling to your preferred backend, Formspree, Netlify Forms, PHP endpoint, CRM or email service before production submission.

## Source basis
Content and photographs were derived from the supplied company profile PDF. Where the PDF contained inconsistent wording/figures, this website keeps the source terminology rather than silently correcting it.
